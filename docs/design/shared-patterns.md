# Shared Patterns

> **Migration revision approved.** User approved `migration-draft-1` in this chat on 2026-10-09. Historical source knowledge is preserved; this file does not establish implementation, runtime validation, deployment, or release completion.

## Forms and action feedback

Use labelled, keyboard-operable controls. Show sending, uploading, joining, voting, and failed-action states clearly. Invitation mismatch, expiry, revocation, and full capacity have distinct explanations.

## Access and authority

Show current role and view/edit state in text. Distinguish workspace administration from team-content access. A denied action explains the current restriction; visible controls update when access changes.

## Confirmations

Workspace/team/space deletion and leaving identify what changes. A call switch names the current-call disconnection. Task-block removal distinguishes hiding a view from deleting data.

## Empty and unavailable states

Empty teams/task views and inaccessible resources have clear feedback. Closed polls and resolved questions state why participation controls are unavailable.

## Collaboration and synchronization

Show collaborator presence, synchronization state, pending local edits, and failed changes. Agent actions carry member-via-agent attribution.

## Calls

Show connecting, connected, reconnecting, and disconnected states. Microphone/camera begin off. Device failures leave the medium off and explain the failure. Compact controls persist across navigation; minimizing and leaving are distinct.

## Usage and limits

Show member capacity, pooled storage, and call usage with text values. Explain blocked joins/growth and over-limit downgrade states. Pending local work remains visible.
