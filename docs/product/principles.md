# Principles & Non-Goals

> **Migration revision approved.** User approved `migration-draft-1` in this chat on 2026-10-09. Historical source knowledge is preserved; this file does not establish implementation, runtime validation, deployment, or release completion.

## Principles

* **Revive the existing product.** Wodge remains a collaborative workspace and portfolio showcase built from the capstone code.
* **Demonstrate working capabilities.** Workspace membership, team access, discussions, pages and tasks, calls, and Stripe test billing remain part of the showcase.
* **Preserve local-first collaboration.** Replicache handles structured local-first state; Yjs handles collaborative text.
* **Respect current access.** Team membership and additive role grants govern content access. Agents act within the member’s permissions.
* **Keep the visual direction recognizable.** Usability improvements accompany the revival; a full visual redesign has not been selected.
* **Separate the backend.** Shared APIs serve the web app and can support a future mobile client.
* **Bound the investment.** Operating spend should stay near $5/month and must not exceed $10/month. The approved revival delivery window is October 4–11, 2026, with weekday work after work.

## Non-goals

* A mobile app in this revival.
* Migration of old accounts or deployment data.
* Workspace-wide groups or a built-in Moderator role.
* Standalone team or workspace resource libraries.
* A hosted AI writer or model.
* Deeper autonomous agent workflows.
* Live payments or a validated commercial subscription price.
* Ongoing active maintenance after the showcase.
